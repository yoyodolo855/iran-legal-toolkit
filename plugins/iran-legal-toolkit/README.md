# پلاگین جعبه‌ابزار حقوقی ایران

این پوشه خودِ پلاگین است. راهنمای کامل، فایل‌های دانلودی و نتیجهٔ آزمون‌ها در [صفحهٔ اصلی پروژه](../../README.md) هست.

| بخش | کاربرد |
|-----|--------|
| بخش `iran-legal-core` | روش کار، مهلت‌ها، مرجع صالح، قوانین تازه‌تغییرکرده و راه‌های وکیل رایگان |
| بخش `iran-civil-litigation` | دادخواست، لایحه، اظهارنامه، تأمین خواسته، واخواهی، تجدیدنظر، اعسار و اجرای حکم |
| بخش `iran-criminal-procedure` | شکواییه، اعتراض به قرار، دفاع و حقوق فرد بازداشت‌شده |
| بخش `iran-contracts-deeds` | قرارداد، اجاره‌نامه، مبایعه‌نامه، اقرارنامه، تعهدنامه، چک و سفته |
| بخش `iran-labor-law` | دعاوی ادارهٔ کار، مزایا، اخراج و ارقام مزد ۱۴۰۵ |
| بخش `iran-family-law` | مهریه، نفقه، طلاق، حضانت، جهیزیه، ارث و انحصار وراثت |
| بخش `iran-property-lease` | اجاره و ودیعه، تخلیه، خرید و فروش ملک، الزام به تنظیم سند، تصرف عدوانی، ملک مشاع |
| بخش `iran-law-texts` | متن کامل چهارده قانون و آیین‌نامه، از جمله قانون مدنی، آیین دادرسی مدنی، قانون کار و قانون صدور چک، با ابزار پیدا کردن ماده |

پرونده‌های آزمون هر بخش در پوشهٔ `evals` همان بخش است.
