# مواد پرکاربرد (مدنی)

خلاصه‌ها مضمون ماده است، نه متن آن. برای نقل مستقیم، متن رسمی را ببین.

## قانون آیین دادرسی مدنی (۱۳۷۹)

| ماده | مضمون |
|------|-------|
| ۲ | دادگاه بدون درخواست ذی‌نفع رسیدگی نمی‌کند |
| ۳ | قاضی نمی‌تواند به بهانهٔ سکوت یا ابهام قانون از رسیدگی خودداری کند |
| ۱۱ تا ۱۳ | صلاحیت محلی (اقامتگاه خوانده، محل ملک، محل قرارداد) |
| ۲۶، ۲۷ | تشخیص صلاحیت با همان دادگاه؛ قرار عدم صلاحیت و ارسال پرونده |
| ۴۸، ۵۱ | شروع رسیدگی با دادخواست؛ شرایط دادخواست |
| ۵۳ تا ۵۶ | نقص دادخواست و رفع آن |
| ۵۷ | پیوست‌کردن رونوشت گواهی‌شدهٔ اسناد |
| ۴۹ | تاریخ رسید دادخواست به دفتر، تاریخ اقامهٔ دعواست |
| ۵۵ | هزینهٔ آگهی ظرف یک ماه؛ وگرنه رد دادخواست |
| ۶۱، ۶۲ | بهای خواسته همان است که خواهان نوشته؛ ارز به نرخ رسمی روز تقدیم؛ اقساط: جمع همه، و اگر نامحدود است جمع ده سال |
| ۶۴ | فاصلهٔ ابلاغ تا جلسه دست‌کم ۵ روز؛ اگر نشانی یکی از طرفین خارج از کشور است، دو ماه |
| ۶۶ | نقصی که قاضی می‌بیند: اخطار ۱۰ روزه؛ قرار رد ظرف ۱۰ روز قابل شکایت |
| ۸۴ | یازده ایراد (عدم صلاحیت، امر مطروحه، عدم اهلیت، عدم توجه دعوا، احراز نشدن سمت، امر مختوم، بی‌اثر بودن دعوا، نامشروع بودن، جزمی نبودن، ذی‌نفع نبودن، خارج از موعد بودن) |
| ۸۷، ۹۰ | ایرادها تا پایان اولین جلسه؛ اگر دیرتر گفته شود، دادگاه فقط مکلف نیست جدا از ماهیت رأی بدهد |
| ۸۹ | نتیجهٔ ایرادها: عدم صلاحیت، ارسال پرونده (امر مطروحه)، یا قرار رد دعوا |
| ۹۵ | غیبت خواهانی که برای توضیح دعوت شده، یا غیبت هر دو طرف، می‌تواند به ابطال دادخواست برسد |
| ۹۶ | اصل سندها را باید در جلسه آورد؛ وگرنه سند عادیِ انکارشده از دلایل بیرون می‌رود یا دادخواست ابطال می‌شود |
| ۹۷ | مهلت به خواهان برای پاسخ به دلیل تازهٔ خوانده |
| ۹۸ | افزایش خواسته تا پایان اولین جلسه؛ کاهش در همهٔ مراحل |
| ۱۰۲ | موارد نوشتن عین گفتهٔ طرفین در صورت‌جلسه (اقرار، استفاده از گفتهٔ طرف، نظر دادگاه) |
| ۱۰۶ | بازداشت یا سفر ضروری یکی از طرفین دادرسی را متوقف نمی‌کند؛ مهلت برای گرفتن وکیل |
| ۱۰۷ | استرداد: دادخواست تا اولین جلسه (ابطال)؛ دعوا تا پایان دادرسی (رد دعوا)؛ بعد از ختم مذاکرات فقط با رضایت خوانده یا صرف‌نظر کامل (سقوط دعوا؛ طرح دوباره ممکن نیست) |
| ۱۰۹، ۱۱۰ | تأمین دعوای واهی به درخواست خوانده؛ در چک، سفته، برات و سند رسمی ممکن نیست |
| ۱۰۸ تا ۱۲۹ | تأمین خواسته (لغو به درخواست خوانده اگر دعوای اصلی در ۱۰ روز طرح نشود: ۱۱۲؛ اعتراض ۱۰ روزه: ۱۱۶؛ خسارت ناشی از تأمین ظرف ۲۰ روز: ۱۲۰) |
| ۱۳۰ تا ۱۴۳ | ورود ثالث، جلب ثالث (اعلام در جلسهٔ اول و دادخواست ظرف سه روز: ۱۳۵)، دعوای تقابل (۱۴۳) |
| ۱۴۹ تا ۱۵۵ | تأمین دلیل |
| ۱۵۶، ۱۵۷ | اظهارنامه |
| ۱۵۸ تا ۱۷۷ | تصرف عدوانی، ممانعت از حق، مزاحمت |
| ۱۷۸ تا ۱۹۳ | سازش و درخواست سازش |
| ۱۹۷، ۱۹۸ | اصل برائت؛ اصل بقای حق یا دینِ ثابت‌شده |
| ۱۹۹ | دادگاه هر تحقیقی که برای کشف حقیقت لازم باشد انجام می‌دهد |
| ۲۰۲ تا ۲۰۵ | اقرار |
| ۲۰۶ تا ۲۲۸ | اسناد؛ انکار (سند منسوب به خود) و تردید (سند منسوب به دیگری): ۲۱۶؛ «حتی‌الامکان» تا اولین جلسه، و در رأی غیابی ضمن واخواهی: ۲۱۷؛ استرداد سند: ۲۱۸؛ جعل با دلیل: ۲۱۹ |
| ۲۲۹ تا ۲۴۷ | گواهی (شهادت): نصاب: ۲۳۰؛ آوردن شاهد با خود طرف: ۲۳۲؛ جرح و مهلت یک هفته: ۲۳۴؛ احضار دست‌کم یک هفته پیش از جلسه: ۲۴۲ |
| ۲۴۸ تا ۲۵۶ | معاینهٔ محل و تحقیق محلی؛ غیبت طرف مانع نیست: ۲۵۴؛ فراهم نکردن وسیله: ۲۵۶ |
| ۲۵۷ تا ۲۶۹ | کارشناسی (دستمزد ظرف یک هفته: ۲۵۹؛ اعتراض یک هفته: ۲۶۰؛ نظر خلاف واقع: ۲۶۵) |
| ۲۷۰ تا ۲۸۹ | سوگند (فقط با درخواست: ۲۸۳؛ ترتیب و رد سوگند: ۲۷۲ تا ۲۷۴؛ یک شاهد و سوگند: ۲۷۷؛ دعوا بر میت: ۲۷۸ و ۲۷۹) |
| ۳۰۳ تا ۳۰۸ | حکم حضوری و غیابی، واخواهی (ضامن یا تأمین برای اجرای حکم غیابی: تبصرهٔ ۲ مادهٔ ۳۰۶) |
| ۳۱۰ تا ۳۲۵ | دستور موقت (جدا قابل اعتراض نیست و اجرا با تأیید رئیس حوزه: ۳۲۵) |
| ۳۳۰ تا ۳۶۵ | تجدیدنظر (آرای قابل تجدیدنظر: ۳۳۱ و ۳۳۲؛ مهلت: ۳۳۶؛ جهات: ۳۴۸) |
| ۳۶۶ تا ۴۱۶ | فرجام‌خواهی |
| ۴۱۷ تا ۴۲۵ | اعتراض شخص ثالث |
| ۴۲۶ تا ۴۴۱ | اعادهٔ دادرسی (جهات: ۴۲۶) |
| ۳۳۷ تا ۳۴۰ | مهلت تازه با فوت، حجر یا ورشکستگی؛ دادخواست از بازداشتگاه؛ تجدیدنظر خارج از مهلت با عذر موجه |
| ۴۴۲ تا ۴۵۳ | مواعد (مقیم خارج: همهٔ مهلت‌ها دو ماه، ۴۴۶؛ منع تجدید مهلت‌های اعتراض به رأی، ۴۵۱) |
| ۴۵۴ تا ۵۰۱ | داوری |
| ۵۰۲ تا ۵۱۴ | هزینهٔ دادرسی و اعسار |
| ۵۱۵ تا ۵۲۲ | مطالبهٔ خسارت، خسارت دادرسی، خسارت تأخیر تأدیه |

## قانون مدنی (قواعد عمومی)

| ماده | مضمون |
|------|-------|
| ۱۰ | اعتبار قراردادهای خصوصی، اگر خلاف صریح قانون نباشد |
| ۳۰، ۳۱ | مالک حق همه‌گونه تصرف دارد؛ هیچ مالی را نمی‌توان از تصرف صاحبش بیرون کرد مگر به حکم قانون |
| ۳۵ | تصرف به عنوان مالکیت، دلیل مالکیت است مگر خلافش ثابت شود |
| ۱۸۳، ۱۹۰ | تعریف عقد؛ شرایط اساسی صحت (قصد و رضا، اهلیت، موضوع معین، جهت مشروع) |
| ۲۱۹، ۲۲۰ | لزوم قراردادها؛ التزام به نتایج عرفی و قانونی عقد |
| ۲۲۱، ۲۲۶ تا ۲۳۰ | خسارت عدم انجام تعهد، مطالبه پس از موعد، قوهٔ قاهره (۲۲۷ و ۲۲۹)، وجه التزام (۲۳۰) |
| ۲۳۷ تا ۲۳۹ | الزام به انجام شرط فعل، انجام به هزینهٔ متعهد، حق فسخ |
| ۲۶۴ | راه‌های سقوط تعهد؛ از جمله وفای به عهد (پرداخت) |
| ۲۶۵ | هر کس مالی به دیگری بدهد ظاهر در عدم تبرع است |
| ۳۰۱، ۳۰۳ | دریافتِ ناروا و تکلیف به رد |
| ۳۰۸، ۳۱۱ | غصب و تکلیف به رد عین |
| ۳۲۸، ۳۳۱ | اتلاف و تسبیب |
| ۱۲۵۷ | هر کس مدعی حقی باشد باید آن را اثبات کند |
| ۱۲۵۸ | دلایل اثبات دعوا: اقرار، اسناد کتبی، شهادت، امارات، قسم |
| ۱۲۷۷، ۱۲۸۰ | انکار بعد از اقرار شنیده نمی‌شود مگر با ادعای اشتباه یا عذر موجه که باید ثابت شود؛ اقرار کتبی مثل اقرار شفاهی است |
| ۱۲۸۴ تا ۱۳۰۵ | اسناد (سند رسمی: ۱۲۸۷؛ اعتبار سند عادی: ۱۲۹۱ تا ۱۲۹۳؛ امضا علیه امضاکننده دلیل است: ۱۳۰۱) |
| ۱۳۲۵ | در دعوایی که با شهادت ثابت می‌شود، مدعی می‌تواند حکم را به سوگند منکر منوط کند |
