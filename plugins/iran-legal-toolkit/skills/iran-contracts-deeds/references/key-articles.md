# مواد پرکاربرد قانون مدنی در قراردادها

خلاصه‌ها مضمون ماده است، نه متن آن.

## قواعد عمومی قراردادها

| ماده | مضمون |
|------|-------|
| ۱۰ | آزادی قراردادی |
| ۱۸۳ تا ۱۸۹ | تعریف و اقسام عقد (لازم، جایز، خیاری، منجّز، معلّق) |
| ۱۹۰ | شرایط اساسی صحت معامله |
| ۱۹۱ تا ۱۹۴ | قصد و نحوهٔ ابراز آن |
| ۱۹۵ | معامله در حال مستی، بیهوشی یا خواب باطل است |
| ۱۹۹ تا ۲۰۹ | اشتباه و اکراه؛ معاملهٔ اکراهی با امضای بعدی نافذ می‌شود |
| ۲۱۰ تا ۲۱۳ | اهلیت؛ معاملهٔ محجورین |
| ۲۱۴ تا ۲۱۶ | مورد معامله باید مال یا عمل، دارای منفعت عقلایی، مشروع و معلوم باشد |
| ۲۱۷ و ۲۱۸ | جهت معامله؛ معامله به قصد فرار از دین |
| ۲۱۹ | عقود بین طرفین و قائم‌مقام آن‌ها لازم‌الاتباع است |
| ۲۲۰ | التزام به نتایج عرفی و قانونی |
| ۲۲۱ | مسئولیت خسارت در صورت تصریح، عرف یا قانون |
| ۲۲۳ | اصل صحت معاملات |
| ۲۲۴ و ۲۲۵ | الفاظ عقد بر معنای عرفی حمل می‌شود؛ متعارف مثل تصریح است |
| ۲۲۶ تا ۲۳۰ | خسارت عدم انجام تعهد و وجه التزام |
| ۲۳۱ | اثر نسبی قرارداد |
| ۲۳۲ تا ۲۴۶ | شروط ضمن عقد |
| ۲۴۷ تا ۲۶۳ | معاملهٔ فضولی |
| ۲۶۴ | راه‌های سقوط تعهد: وفای به عهد، اقاله، ابراء، تبدیل تعهد، تهاتر، مالکیت مافی‌الذمه |
| ۲۷۷ | متعهد نمی‌تواند طلبکار را به قبول بخشی از طلب مجبور کند؛ دادگاه می‌تواند مهلت یا قسط بدهد |
| ۲۸۳ | اقاله (برهم‌زدن قرارداد با توافق) |
