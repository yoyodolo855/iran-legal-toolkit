# تعرفهٔ دفاتر خدمات الکترونیک قضایی، سال ۱۴۰۵

منبع: جدول «تعرفهٔ مصوب کارگروه سال ۱۴۰۵» (۳۹ درصد افزایش نسبت به ۱۴۰۴). این‌ها کارمزد دفتر خدمات است، **نه هزینهٔ دادرسی دادگاه**؛ هزینهٔ دادرسی جداست و به خواسته بستگی دارد.

| خدمت | ریال |
|------|------|
| تنظیم و ثبت اظهارنامه | ۱٬۱۸۱٬۵۰۰ |
| تنظیم و ثبت شکواییه یا اعلام جرم | ۱٬۴۴۵٬۶۰۰ |
| تنظیم و ثبت دادخواست یا درخواست بدوی | ۱٬۴۴۵٬۶۰۰ |
| تنظیم و ثبت دادخواست یا درخواست اعتراضی (تجدیدنظر، واخواهی و …) | ۱٬۴۴۵٬۶۰۰ |
| دادخواست ورود یا جلب ثالث، اعادهٔ دادرسی، دعوای تقابل | ۱٬۴۴۵٬۶۰۰ |
| تنظیم و ثبت لایحه | ۱٬۱۸۱٬۵۰۰ |
| واخواست اسناد تجاری | ۹۴۵٬۲۰۰ |
| افزودن هر نفر (خواهان، خوانده، وکیل، نماینده) | ۱۳۲٬۰۵۰ |
| افزودن هر صفحه پیوست | ۱۳۲٬۰۵۰ |
| **تدوین** دادخواست، شکواییه یا درخواست، برای کسی که متن آماده نیاورده | ۲٬۸۱۴٬۷۵۰ |
| استشهادیهٔ الکترونیک (همهٔ شاهدان با هم) | ۸۳۴٬۰۰۰ |
| ثبت درخواست داوری | ۱٬۰۳۵٬۵۵۰ |
| تقاضای وثیقه‌گذار و کفیل | ۱٬۱۸۱٬۵۰۰ |

| تحویل رمز حساب کاربری | ۱۰۴٬۲۵۰ |
| تکمیل احراز هویت | ۱۴۵٬۹۵۰ |
| گواهی عدم سوءپیشینه | ۲۱۵٬۴۵۰ |
| اعتراض به گزارش کروکی تصادف | ۱٬۱۹۰٬۰۰۰ |

**نکته‌هایی که به کاربر بگو:**

- اگر متن دادخواست یا شکواییه را **آماده و تایپ‌شده** ببرد، کارمزد «تدوین» (۲٬۸۱۴٬۷۵۰ ریال) را نمی‌دهد و فقط کارمزد ثبت را می‌پردازد. متنی که با این بسته نوشته می‌شود همین کار را می‌کند.
- هر نفر اضافه و هر صفحهٔ پیوست هزینه دارد؛ پیوست‌های تکراری نبرد.
- با حساب کاربری عدل ایران و احراز هویت، بعضی کارها (مشاهدهٔ ابلاغ، پیگیری) بدون مراجعه انجام می‌شود.
- برای ناتوانی از پرداخت **هزینهٔ دادرسی دادگاه**، دادخواست اعسار بدهد؛ این کارمزد دفتر را شامل نمی‌شود.
