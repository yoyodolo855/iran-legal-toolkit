# حقوق متهم و فرد بازداشت‌شده

این‌ها حقوق مکتوب در قانون است. اگر در عمل رعایت نشده، کمک کن کاربر آن را کتبی و با استناد به ماده مطالبه و در پرونده ثبت کند.

## قانون اساسی

| اصل | مضمون |
|-----|-------|
| ۲۲ | مصونیت حیثیت، جان، مال، حقوق، مسکن و شغل اشخاص |
| ۲۳ | تفتیش عقاید ممنوع است |
| ۲۵ | بازرسی نامه‌ها، ضبط مکالمات و هرگونه تجسس ممنوع است مگر به حکم قانون |
| ۳۲ | هیچ‌کس را نمی‌توان دستگیر کرد مگر به حکم و ترتیب قانون. اتهام و دلایل آن باید بلافاصله کتباً ابلاغ و تفهیم شود و ظرف حداکثر ۲۴ ساعت پرونده به مرجع قضایی فرستاده شود |
| ۳۴ | دادخواهی حق مسلّم هر فرد است |
| ۳۵ | حق انتخاب وکیل در همهٔ دادگاه‌ها |
| ۳۶ | مجازات فقط به حکم دادگاه صالح و به‌موجب قانون |
| ۳۷ | اصل برائت |
| ۳۸ | هرگونه شکنجه برای گرفتن اقرار یا اطلاع ممنوع است؛ اقرار و شهادت و سوگندِ ناشی از اجبار اعتبار ندارد |
| ۳۹ | هتک حرمت بازداشت‌شده یا زندانی ممنوع است |
| ۱۶۵ و ۱۶۸ | علنی‌بودن محاکمه؛ رسیدگی به جرایم سیاسی و مطبوعاتی علنی و با حضور هیأت منصفه |

| ماده | مضمون |

| ۵ | متهم باید در اسرع وقت از موضوع و ادلهٔ اتهام آگاه شود و از حق دسترسی به وکیل بهره‌مند باشد |
| ۶ | متهم، بزه‌دیده و شاهد باید از حقوق خود در فرایند دادرسی آگاه شوند |

| ۴۶ | ضابطان فقط در جرم مشهود می‌توانند بدون دستور قضایی متهم را نگه دارند و حداکثر تا ۲۴ ساعت |
| ۴۸ | با شروع تحت‌نظر، متهم می‌تواند تقاضای حضور وکیل کند. تبصره: در جرایم علیه امنیت و جرایم سازمان‌یافتهٔ مشخص، در مرحلهٔ تحقیقات مقدماتی وکیل باید از میان وکلای مورد تأیید رئیس قوهٔ قضاییه باشد |

| ۵۰ | فرد تحت‌نظر می‌تواند با تلفن یا هر وسیلهٔ دیگر خانواده را باخبر کند، مگر ضابط به ضرورت تشخیص دهد که نباید؛ در این صورت باید از مقام قضایی دستور بگیرد |
| ۵۱ | معاینهٔ پزشکی فرد تحت‌نظر به درخواست او یا بستگانش |

| ۵۳ | ضابط باید اظهارات، علت، ساعت شروع، مدت بازجویی و استراحت را صورت‌جلسه کند و به امضای متهم برساند، و آغاز و پایان تحت‌نظر را در دفتر خاص ثبت کند |
| ۶۰ | اجبار، اکراه، الفاظ موهن، پرسش تلقینی یا اغفال‌کننده در بازجویی ممنوع است و اظهاراتِ حاصل از آن معتبر نیست |
| ۱۶۸ | بازپرس نباید بدون دلیل کافی کسی را احضار یا جلب کند |
| ۱۷۰ | علت احضار باید در احضاریه نوشته شود |
| ۱۹۰ | متهم می‌تواند در تحقیقات مقدماتی یک وکیل همراه داشته باشد؛ بازپرس باید این حق را پیش از شروع تحقیق تفهیم کند |
| ۱۹۵ | بازپرس پیش از تحقیق باید موضوع اتهام و ادلهٔ آن را صریح تفهیم کند |
| ۱۹۷ | حق سکوت؛ سکوت در صورت‌جلسه قید می‌شود |

| ۲۱۷ | فهرست قرارهای تأمین، از التزام تا بازداشت موقت |
| ۲۳۷ و ۲۳۸ | بازداشت موقت فقط در جرایم و شرایط مشخص مجاز است |
| ۲۴۲ | بازبینی دوره‌ای بازداشت؛ سقف مدت بازداشت |

| ماده | مضمون |
|------|-------|
| ۲ | جرم فقط رفتاری است که قانون برایش مجازات تعیین کرده |
| ۱۰ | قانون بعدی اگر مساعدتر باشد به گذشته هم اعمال می‌شود |
| ۱۲ | مجازات فقط به حکم دادگاه صالح و با رعایت قانون |

| تعزیرات ۵۷۸ | مأموری که برای گرفتن اقرار متهم را آزار بدنی دهد مجازات می‌شود |

## کارهایی که خانوادهٔ فرد بازداشت‌شده می‌تواند بکند

1. از دادسرای محل پیگیری کند که فرد کجا و به چه اتهامی نگهداری می‌شود؛ ضابط باید ظرف یک ساعت مشخصات او را به دادسرا اعلام کرده باشد (مادهٔ ۴۹).
2. فوراً وکیل بگیرد؛ اگر توان ندارد، درخواست وکیل معاضدتی بدهد.
3. اگر قرار وثیقه یا کفالت صادر شده، سند ملک یا کفیل معرفی کند. وثیقه می‌تواند پول، ضمانت‌نامهٔ بانکی، ملک یا مال منقول باشد.
4. به قرار بازداشت موقت ظرف ۱۰ روز کتباً اعتراض کند (الگوی ۵-ب در فایل الگوها) و همزمان تبدیل قرار را بخواهد (الگوی ۵).
5. اگر بیماری یا دارو مطرح است، کتباً درخواست معاینه و درمان بدهد و رونوشت نگه دارد.
6. از هر درخواست کتبی رونوشت و شمارهٔ ثبت بگیرد.
