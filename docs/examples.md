# نمونه درخواست‌ها

این نمونه‌ها را می‌توانید کپی کنید و با ماجرای خودتان عوض کنید.

## کار و کارگری

```
دو سال و چهار ماه در یک کارگاه مبل‌سازی در کرج کار کردم. قرارداد کتبی نداشتیم و حقوقم ماهی ۱۲ میلیون تومان کارت‌به‌کارت می‌آمد. بیمه‌ام نکرد. سه ماه آخر حقوق نداد و وقتی گفتم بیمه‌ام کن گفت دیگر نیا. الان دو هفته است بیکارم. یک شکایت‌نامهٔ کامل برای ادارهٔ کار بنویس.
```

## چک برگشتی

```
یک چک ۸۰ میلیون تومانی از همکارم دارم که در سامانهٔ صیاد ثبت شده بود. تاریخ چک ۲۰ مرداد ۱۴۰۵ بود و همان روز برگشت خورد و گواهی عدم پرداخت گرفتم. سریع‌ترین راه گرفتن پولم چیست؟ دادخواستش را هم بنویس.
```

## حکم غیابی

```
۱۸ روز پیش در ثنا یک رأی غیابی برایم آمد که باید ۳۰۰ میلیون تومان به کسی بدهم. خبر نداشتم دادگاهی هست چون نشانی قدیمی‌ام را داده بود. این پول را قبلاً به او داده‌ام و رسید بانکی دارم. چه کار کنم؟
```

## کلاهبرداری اینترنتی

```
از یک صفحهٔ اینستاگرامی گوشی خریدم و ۱۵ میلیون تومان کارت‌به‌کارت کردم. بعد مرا مسدود کرد. شماره کارت و نام صاحب کارت و تصویر گفت‌وگوها را دارم. شکواییه بنویس.
```

## بازداشت

```
برادرم را دیروز از سر کار بردند. نمی‌دانیم کجاست و به چه اتهامی. ما چه حقی داریم و الان چه کار کنیم؟
```

## اجاره‌نامه

```
می‌خواهم آپارتمانم را در تهران یک‌ساله اجاره بدهم؛ ۵۰۰ میلیون تومان رهن و ماهی ۱۵ میلیون اجاره، بدون بنگاه. یک اجاره‌نامهٔ کامل بنویس که اگر مستأجر تخلیه نکرد به مشکل نخورم.
```

## مهریه و طلاق

```
شوهرم دو سال است خانه را ترک کرده و خرجی نمی‌دهد. مهریه‌ام ۲۰۰ سکه عندالمطالبه است و سند ازدواج رسمی داریم. یک آپارتمان به نام خودش دارد. می‌خواهم هم مهریه‌ام را بگیرم و هم طلاق. از کجا شروع کنم؟ دادخواستش را هم بنویس.
```

## حضانت

```
طلاق گرفته‌ایم و پسرم هشت ساله است و پیش مادرش زندگی می‌کند. مادرش می‌خواهد ازدواج کند و بچه را به شیراز ببرد. من تهرانم. حضانت با کیست و آیا می‌تواند بچه را ببرد؟
```

## ارث

```
پدرم فوت کرده. مادرم زنده است و ما دو برادر و یک خواهریم. پدرم یک خانه به ارزش ۱۲ میلیارد ریال و ۳ میلیارد ریال پول در حساب داشته. سهم هر کدام چقدر است و چه کارهایی باید بکنیم؟
```

## ودیعهٔ اجاره

```
قرارداد اجاره‌ام دو هفته پیش تمام شد و اجاره‌نامهٔ بنگاهی با کد رهگیری و دو شاهد داریم. صاحبخانه می‌گوید تا خانه را خالی نکنی پول پیشت را نمی‌دهم و دیروز قفل پارکینگ را هم عوض کرده. بدون پول پیش نمی‌توانم جای دیگری اجاره کنم. چه کار کنم؟
```

## سند ملک

```
یک آپارتمان با قولنامهٔ بنگاهی خریدم و ۹۰ درصد پول را داده‌ام. قرار بود ۱۵ مهر در دفترخانه سند بزند ولی نیامد و شنیده‌ام می‌خواهد به کس دیگری بفروشد. ملک سند تک‌برگ دارد. چه کار کنم؟
```
